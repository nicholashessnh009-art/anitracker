# anitracker
Projeto de AeP do segundo semestre, feito em Python.

O que é?
    é um aplicativo feito para registrar séries (animes) que você assiste. Você pode adicionar qualquer anime que você quiser, adicioná-lo em listas, e o avaliar. A Interface foi feita com PySide6. Para rodar o app, apenas execute o arquivo mainfolder/main.py.

Quais são as dependências/coisas necessárias para o app funcionar?
    Para o app funcionar, você precisa de quatro coisas:
        1 - Conexão à internet;
        2 - PySide6 6.12.0;
        3 - requests 2.34.2;
        4 - Python 3.12+

Como instalar dependências:

    pip install -r dependencias.txt

    OU:

    pip install PySide6==6.12.0
    pip install requests==2.34.2
